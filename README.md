# Python Weather API Project

## About
This project is built using Python and the Open-Meteo API to display the current temperature of a city entered by the user.

## Features
- Enter any city name
- Find city coordinates using the Geocoding API
- Fetch current temperature
- Display a weather report
- Handle invalid city names

## Technologies Used
- Python
- Requests library
- Open-Meteo API

## Installation
Install the required library:

```bash
pip install requests
```

## How to Run
Run the Python file:

```bash
python weather.py
```

Enter a city name when prompted.

## API Used
- Geocoding API: https://geocoding-api.open-meteo.com/
- Weather API: https://open-meteo.com/

## Learning Outcomes
- Python programming
- API integration
- JSON data handling
- Error handling
